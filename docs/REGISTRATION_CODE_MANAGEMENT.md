# 注册码管理

注册码页无需选择角色。支持批量生成、单码停用、解绑、按账号/完整注册码/前缀/批次查询、分页和使用记录；账号按钮打开账号管理详情。

注册校验默认开启。关闭后注册接口允许不提供注册码；重新开启后要求有效注册码。策略存于独立管理表，通过已有管理会话和 CSRF 写接口修改，读取失败时拒绝注册。

升级前执行网关 `--init-management-schema`，创建 `*_login_codes_policy` 表。随后更新网关、重新构建并发布 GM Console 和登录器。旧登录器仍可能在本地要求输入注册码，需升级登录器才能空码注册。

新使用记录保存关联账号；解绑后仍可按历史账号检索。旧记录未保存的历史账号无法补回；仍绑定的旧码可显示账号和激活时间。完整注册码仅生成时返回，数据库保存摘要。

本次未运行构建和自动测试：当前机器缺少 Go、npm、.NET SDK 和 Flutter 工具链。真机验收需覆盖开关切换、空码注册、无效码拒绝、成功绑定、解绑后历史查询和账号跳转。
